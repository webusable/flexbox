Carrusel de imágenes con CSS3

2. Guía Explicativa Paso a Paso

Cómo funciona conceptualmente la arquitectura semántica e interacción CSS3

1

Estructura Semántica HTML5

Utilizamos el contenedor <article class="carousel-container"> con un encabezado <h3>. La galería es una lista <ul class="carousel-track"> compuesta por 5 elementos <li class="slide"> que contienen figuras semánticas <figure> con sus descripciones <figcaption>.

2

Imágenes en `figure::before`

En lugar de usar etiquetas <img> directas, cargamos las imágenes mediante el pseudo-elemento CSS figure::before utilizando background-image. Esto nos permite un encuadre perfecto con background-size: cover y efectos de zoom al hacer hover.

3

Desplazamiento con `transform`

La lista <ul> tiene un ancho del 500%. Al activar un radio button con :checked, el selector de hermano adyacente general (~) aplica la propiedad transform: translateX(-20%), desplazar la tira para revelar cada foto suavemente.

4

Controles Semánticos NAV > UL > LI

Todos los puntos indicativos y flechas de dirección están estructurados en listas semánticas <nav><ul><li>. Las etiquetas <label for="slideX"> activan los inputs sin necesidad de una sola línea de código JavaScript.

3. Código HTML5 Semántico y CSS3 Completo

Copia directamente este código en un archivo de texto con extensión `.html` y ábrelo en tu navegador

    /* Título h3 */

      margin-bottom: 20px;
      text-align: center;
    }

    /* Marco del viewport */
    .carousel-viewport {

      width: 100%;
      height: 420px;
      overflow: hidden;

    }

      transition: transform 0.6s cubic-bezier(0.25, 1, 0.5, 1);

      position: relative;
      width: 100%;
      height: 100%;
      display: flex;
      align-items: flex-end;

      position: absolute;

      background-size: cover;
      background-position: center;
      z-index: 1;
    }

    ul.carousel-track li:nth-child(2) figure::before { background-image: url('https://images.unsplash.com/photo-1511447333015-45b65e60f6d5?w=1200'); }
    ul.carousel-track li:nth-child(3) figure::before { background-image: url('https://images.unsplash.com/photo-1470071459604-3b5ec3a7fe05?w=1200'); }
    ul.carousel-track li:nth-child(4) figure::before { background-image: url('https://images.unsplash.com/photo-1451187580459-43490279c0fa?w=1200'); }
    ul.carousel-track li:nth-child(5) figure::before { background-image: url('https://images.unsplash.com/photo-1472214103451-9374bd1c798e?w=1200'); }

    /* Leyenda figcaption */

      position: relative;
      z-index: 2;
      width: 100%;
      padding: 16px 24px;
      background: linear-gradient(to top, rgba(15, 23, 42, 0.95), transparent);
      color: #ffffff;
      font-weight: 600;
    }

    /* Desplazamiento mediante CSS3 transform */
    #slide1:checked ~ .carousel-viewport ul.carousel-track { transform: translateX(0%); }
    #slide2:checked ~ .carousel-viewport ul.carousel-track { transform: translateX(-20%); }
    #slide3:checked ~ .carousel-viewport ul.carousel-track { transform: translateX(-40%); }
    #slide4:checked ~ .carousel-viewport ul.carousel-track { transform: translateX(-60%); }
    #slide5:checked ~ .carousel-viewport ul.carousel-track { transform: translateX(-80%); }

    /* Navegación de Puntos: NAV > UL > LI */
    nav.carousel-dots-nav { margin-top: 18px; }
    nav.carousel-dots-nav ul.carousel-dots-list {
      display: flex; justify-content: center; gap: 10px; list-style: none;
    }
    nav.carousel-dots-nav ul.carousel-dots-list li label {
      display: block; width: 12px; height: 12px;
      background-color: #475569; border-radius: 9999px; cursor: pointer; transition: all 0.3s;
    }

    #slide1:checked ~ nav.carousel-dots-nav ul li label[for="slide1"],
    #slide2:checked ~ nav.carousel-dots-nav ul li label[for="slide2"],
    #slide3:checked ~ nav.carousel-dots-nav ul li label[for="slide3"],
    #slide4:checked ~ nav.carousel-dots-nav ul li label[for="slide4"],
    #slide5:checked ~ nav.carousel-dots-nav ul li label[for="slide5"] {
      background-color: #38bdf8; width: 36px;
    }

    /* Navegación de Flechas: NAV > UL > LI */
    nav.carousel-arrows-nav ul.carousel-arrows-list { list-style: none; }
    nav.carousel-arrows-nav ul.carousel-arrows-list li.arrow-group {
      display: none; position: absolute; top: 0; left: 0; width: 100%; height: 100%;
      justify-content: space-between; align-items: center; padding: 0 16px;
      pointer-events: none; z-index: 10;
    }
    nav.carousel-arrows-nav ul.carousel-arrows-list li.arrow-group label {
      pointer-events: auto; width: 44px; height: 44px;
      background-color: rgba(15, 23, 42, 0.75); border: 1px solid rgba(255, 255, 255, 0.15);
      color: #fff; border-radius: 50%; display: flex; align-items: center; justify-content: center;
      cursor: pointer;
    }

    #slide1:checked ~ .carousel-viewport nav.carousel-arrows-nav ul li.arrow-1,
    #slide2:checked ~ .carousel-viewport nav.carousel-arrows-nav ul li.arrow-2,
    #slide3:checked ~ .carousel-viewport nav.carousel-arrows-nav ul li.arrow-3,
    #slide4:checked ~ .carousel-viewport nav.carousel-arrows-nav ul li.arrow-4,
    #slide5:checked ~ .carousel-viewport nav.carousel-arrows-nav ul li.arrow-5 {
      display: flex;
    }
  </style>
</head>
