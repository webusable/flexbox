Transiciones CSS3

Pasa el ratón por encima de cada demo (o usa la tecla Tab en las que son botones o enlaces). Después abre el CSS de esta página y busca la clase del ejercicio: está todo comentado.

Recuerda la fórmula: un cambio de estado (normalmente :hover) + una declaración transition escrita en el estado base.

1. width: ensanchar una barra

Pasa de 120 px a 320 px en 0,4 segundos. Es la transición más sencilla: una propiedad, una duración y una curva.

Pasa el ratón
.e1 { width: 120px; transition: width .4s ease; }
.e1:hover { width: 320px; }

Prueba: cambia .4s por 2s y fíjate en cómo se nota la curva ease.

2. height: un panel que se despliega

La altura se anima de 60 px a 170 px. Para que funcione, los dos valores deben ser números: height: auto no se puede animar. El overflow: hidden esconde el texto que todavía no cabe.

Panel

Este texto aparece al crecer la caja. Es el truco básico de los desplegables.

Prueba: añade transition-delay: .3s y observa cómo espera antes de empezar.

3. opacity: desvanecer

La opacidad va de 1 (opaco) a 0,15 (casi transparente). Junto con transform, es la propiedad más recomendable para animar porque el navegador la dibuja con muy poco esfuerzo.

Me desvanezco

Prueba: pon opacity: 0 en el hover. El elemento desaparece a la vista, pero sigue ocupando su sitio y recibiendo clics.

4. color: un enlace que cambia de tono

El color del texto se anima igual que cualquier número: el navegador calcula todos los tonos intermedios entre el azul oscuro y el rojo.

Enlace de ejemplo

Prueba: añade también :active con otro color y haz clic y mantén pulsado.

5. background-color: botón que se rellena

Aquí animamos dos propiedades a la vez, separándolas con una coma: el fondo y el color del texto.

transition: background-color .3s ease, color .3s ease;

Prueba: cambia solo background-color en la transición y deja color fuera. El texto saltará de golpe.

6. transform: mover, girar y escalar

Tres cajas con la misma transición y distinta función de transform. A diferencia de width o margin, transform no empuja a los elementos vecinos.

translate
rotate
scale

Prueba: combina varias funciones en una sola línea, por ejemplo transform: rotate(45deg) scale(1.2);.

7. left y top: recorrer un escenario

Pasa el ratón por el recuadro: la bola viaja hasta la esquina contraria. Para animar left y top el elemento necesita position distinto de static.

Prueba: quita position: absolute de .bola y comprueba que deja de moverse.

8. font-size: texto que crece

El tamaño de letra cambia de 1rem a 2,4rem. Funciona, pero como altera el tamaño de la caja, el contenido de alrededor se reacomoda. Úsalo con moderación.

Haz crecer este texto

Prueba: alternativa más fluida con transform: scale(1.5). Compara las dos.

9. letter-spacing: abrir las letras

El espacio entre letras pasa de 0 a 0,35em. Se usa mucho en menús y botones. Se mide en em para que escale con el tamaño del texto.

ESPACIADO

Prueba: valores negativos, como -0.05em, para juntar las letras.

10. box-shadow: elevar una tarjeta

La sombra pasa de casi plana a «flotando», y la tarjeta sube 6 px. Para que box-shadow se anime con suavidad, las dos sombras deben tener la misma estructura: mismos valores y en el mismo orden.

Prueba: añade una segunda sombra en ambos estados (la inicial puede ser 0 0 0 transparent).

11. Reto: efecto escalonado con transition-delay

Pasa el ratón por el grupo. Todos los cuadrados hacen la misma transición (posición, giro, color y forma), pero cada uno empieza 0,1 s después que el anterior, usando :nth-child().

Tus retos:
  1. Añade un quinto cuadrado y su retardo de 0,4 s.
  2. Haz que el efecto se invierta al salir (pista: pon los transition-delay distintos en el estado base y en el :hover).
  3. Cambia la curva por cubic-bezier(.68,-.55,.27,1.55) para conseguir un rebote.

Resumen: qué se puede animar

Propiedad Tipo de valor Nota
width, height Longitud No se anima desde o hacia auto.
opacity Número (0 a 1) Muy fluida.
color, background-color Color El navegador mezcla los tonos intermedios.
transform Funciones (translate, rotate, scale) La más recomendable para movimiento.
left, top Longitud Requieren position.
font-size, letter-spacing Longitud Pueden reordenar el contenido vecino.
box-shadow Longitudes y color Misma estructura en ambos estados.

Como norma, anima transform y opacity siempre que puedas, y evita transition: all: enumera las propiedades que realmente quieres animar.
