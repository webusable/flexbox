2. Explicación Guiada Paso a Paso

Los 4 pilares clave que hacen funcionar este carrusel con el mínimo código posible.

Paso 1

Estructura HTML5 Semántica

Usamos <article class="carousel-container"> como marco exterior. Dentro colocamos una lista <ul class="carousel-track"> con 5 elementos <li class="slide">. Cada diapositiva utiliza <figure> y <figcaption> para describir la foto.

Paso 2

La Matemática de las Dimensiones

La ventana tiene overflow: hidden para ocultar lo sobrante. La lista <ul> mide width: 500% (5 fotos). Cada <li> mide exactamente un 20% de la tira, equivaliendo exactamente al 100% del marco visible.

Paso 3

Imágenes en `figure::before`

Cargamos las fotos desde CSS mediante el pseudo-elemento figure::before con background-image y background-size: cover. Esto permite que las imágenes se adapten al espacio disponible sin deformarse.

Paso 4

La Regla `@keyframes`

Dividimos la animación en 5 tramos (de 0% a 100%). En cada tramo usamos transform: translateX(-X%) para mover la tira a la izquierda. Dejamos márgenes de porcentaje constantes para que cada foto permanezca pausada un tiempo antes de pasar a la siguiente.

3. Código HTML5 y CSS3 Autónomo

Todo el código guardado en un único archivo listo para abrir en el navegador.

carrusel-basico.html
100% HTML5 & CSS3 
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Carrusel Automático CSS3 Semántico</title>
  <style>
    /* Reset básico */
    * {
      box-sizing: border-box;
      margin: 0;
      padding: 0;
    }

    body {
      font-family: system-ui, -apple-system, sans-serif;
      background-color: #0f172a;
      color: #ffffff;
      display: flex;
      justify-content: center;
      align-items: center;
      min-height: 100vh;
      padding: 20px;
    }

    /* 1. Contenedor Semántico Principal */
    article.carousel-container {
      width: 100%;
      max-width: 650px;
      background-color: #1e293b;
      border: 1px solid #334155;
      border-radius: 16px;
      padding: 20px;
      box-shadow: 0 20px 25px -5px rgba(0, 0, 0, 0.5);
    }

    article.carousel-container h3 {
      text-align: center;
      color: #38bdf8;
      font-size: 1.2rem;
      margin-bottom: 16px;
    }

    /* 2. Marco Visible (Viewport) */
    .carousel-viewport {
      position: relative;
      width: 100%;
      height: 360px;
      overflow: hidden; /* Oculta las diapositivas fuera de marco */
      border-radius: 12px;
    }

    /* 3. Tira Deslizante UL */
    ul.carousel-track {
      display: flex;
      width: 500%; /* 5 fotos x 100% del marco */
      height: 100%;
      list-style: none;
      
      /* Animación en bucle */
      animation: carrusel-auto 20s infinite ease-in-out;
    }

    /* Cada slide ocupa el 20% del total (equivale al 100% del marco) */
    ul.carousel-track li.slide {
      width: 20%;
      height: 100%;
    }

    ul.carousel-track figure {
      position: relative;
      width: 100%;
      height: 100%;
      display: flex;
      align-items: flex-end;
    }

    /* Carga de la imagen mediante figure::before */
    ul.carousel-track figure::before {
      content: "";
      position: absolute;
      top: 0;
      left: 0;
      width: 100%;
      height: 100%;
      background-size: cover;
      background-position: center;
      z-index: 1;
    }

    /* Asignación de imágenes */
    ul.carousel-track li:nth-child(1) figure::before { background-image: url('https://picsum.photos/id/1018/800/500'); }
    ul.carousel-track li:nth-child(2) figure::before { background-image: url('https://picsum.photos/id/1015/800/500'); }
    ul.carousel-track li:nth-child(3) figure::before { background-image: url('https://picsum.photos/id/1019/800/500'); }
    ul.carousel-track li:nth-child(4) figure::before { background-image: url('https://picsum.photos/id/1025/800/500'); }
    ul.carousel-track li:nth-child(5) figure::before { background-image: url('https://picsum.photos/id/1035/800/500'); }

    /* Leyenda Semántica */
    ul.carousel-track figcaption {
      position: relative;
      z-index: 2;
      width: 100%;
      padding: 12px 16px;
      background: linear-gradient(to top, rgba(0,0,0,0.8), transparent);
      color: #ffffff;
      font-weight: bold;
    }

    /* 4. Animación con @keyframes */
    @keyframes carrusel-auto {
      0%, 15%   { transform: translateX(0%); }
      20%, 35%  { transform: translateX(-20%); }
      40%, 55%  { transform: translateX(-40%); }
      60%, 75%  { transform: translateX(-60%); }
      80%, 95%  { transform: translateX(-80%); }
      100%      { transform: translateX(0%); }
    }
  </style>
</head>
<body>

  <!-- Estrutura Semántica HTML5 -->
  <article class="carousel-container">
    <h3>Carrusel de imágenes con CSS3</h3>
    
    <div class="carousel-viewport">
      <ul class="carousel-track">
        <li class="slide"><figure><figcaption>Foto 1</figcaption></figure></li>
        <li class="slide"><figure><figcaption>Foto 2</figcaption></figure></li>
        <li class="slide"><figure><figcaption>Foto 3</figcaption></figure></li>
        <li class="slide"><figure><figcaption>Foto 4</figcaption></figure></li>
        <li class="slide"><figure><figcaption>Foto 5</figcaption></figure></li>
      </ul>
    </div>
  </article>

</body>
</html>
